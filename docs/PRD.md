# PRD - AI应用板块财经舆情监测大屏

## 1. 产品定位

解决AI应用板块舆情分散、热点滞后、情绪难以量化的问题，提供监测-预警-报告-处置全链路产品。

## 2. 目标用户

财经领域从业者：投资研究人员、行业分析师、媒体编辑

## 3. 功能模块

### 3.1 舆情监测
- 板块情绪指数看板（全市场AI应用板块整体情绪）
- 细分主线情绪对比（Agent / AIGC / AI游戏 / AI传媒）
- 个股情绪排行与详情页
- 热点事件实时聚合

### 3.2 舆情预警
- 关键词触发预警（减持、爆雷、监管、收购等）
- 情绪突变检测（情绪指数短期剧烈波动）
- 趋势预判预警（情绪趋势外推）
- 预警推送（大屏弹窗 + 记录列表）

### 3.3 舆情报告
- 日度/周度情绪报告自动生成
- 主线情绪对比分析
- 热点事件归因
- 报告导出

### 3.4 舆情处置
- 预警→人工复核→标记→入库工单流程
- 处置记录查询
- 知识沉淀（历史预警与处置经验）

## 4. 数据来源

| 数据类型 | 来源 | 采集方式 |
|---------|------|---------|
| 股吧评论 | 东方财富网股吧 | Python爬虫 |
| 行情数据 | AKShare接口 | API调用 |
| 资金流向 | AKShare接口 | API调用 |

## 5. 核心指标

- 板块情绪指数（0-100，正面→负面）
- 细分主线情绪指数
- 个股情绪得分
- 热点事件热度值
- 预警触发次数与准确率

## 6. 分析对象

东方财富"AI应用"概念板块，细分四条新兴主线：

| 主线 | 代表个股 |
|------|---------|
| AI Agent | 拓尔思、彩讯股份 |
| AIGC创意营销 | 万兴科技、蓝色光标、易点天下 |
| AI游戏 | 汤姆猫、掌趣科技 |
| AI传媒 | 中文在线、华策影视 |
