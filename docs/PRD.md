# AI应用板块财经舆情监测大屏 PRD

## 一、产品定位
帮助投资者快速感知AI应用概念板块的市场情绪与热点事件，辅助投资决策。

## 二、用户角色（用于画用例图）

| 角色 | 说明 | 核心功能 |
|------|------|---------|
| 访客 | 未登录用户 | 查看板块情绪看板、浏览公开报告 |
| 注册用户 | 已登录普通用户 | 接收预警推送、查看个股详情、收藏关注 |
| 分析师 | 专业用户 | 自定义监测范围、导出报告、设置预警规则 |

## 三、用例图描述（拿去draw.io画）

### 3.1 访客用例
- 查看板块情绪总览大屏
- 查看细分主线情绪对比
- 浏览公开舆情报告

### 3.2 注册用户用例
- 包含访客所有用例
- 查看个股情绪详情
- 收藏关注个股
- 接收预警消息推送

### 3.3 分析师用例
- 包含注册用户所有用例
- 自定义监测股票范围
- 设置预警规则（关键词/阈值/情绪突变）
- 导出舆情报告（PDF/Excel）
- 查看处置工单并复核

## 四、功能需求表（论文第3章用）

| 模块 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| 舆情监测 | 板块情绪总览 | 展示AI应用板块整体情绪指数、正负面占比、热度趋势 | P0 |
| 舆情监测 | 细分主线对比 | Agent/AIGC/AI游戏/AI传媒四条主线情绪横向对比 | P0 |
| 舆情监测 | 个股情绪详情 | 单只股票的情绪指数、帖子热度、情感时间线 | P1 |
| 航情监测 | 热词统计 | 板块高频词、TF-IDF重要特征词展示 | P1 |
| 航情预警 | 关键词预警 | 命中"减持""爆雷""监管"等关键词时触发预警 | P0 |
| 航情预警 | 情绪突变预警 | 个股/板块情绪指数短期剧烈变化时触发 | P1 |
| 航情预警 | 阈值预警 | 情绪指数超过设定阈值时触发 | P2 |
| 航情报告 | 周期报告 | 自动生成日/周/月舆情总结报告 | P0 |
| 航情报告 | 板块对比报告 | 细分主线情绪、热度、事件对比分析 | P1 |
| 航情报告 | 报告导出 | 支持导出PDF/Excel格式 | P2 |
| 航情处置 | 预警工单 | 预警自动生成工单，分配给分析师复核 | P1 |
| 航情处置 | 人工复核 | 分析师标记预警为"有效/误报"，记录处理意见 | P1 |
| 航情处置 | 知识沉淀 | 有效预警入库，形成历史案例库 | P2 |
