# 毕业设计（论文）任务书

**论文题目：大数据视角下半导体板块舆情的多维信息效应实证研究**

---

## 1. 毕业设计（论文）的主要内容

半导体产业是国家的战略性支柱产业。近年来，随着国产替代进程加速、全球科技竞争日趋激烈，这一行业成为资本市场与科技领域最受关注的赛道之一。围绕行业政策、技术突破、市场供需与国际局势，每天都有海量信息产生，并广泛分布在证券时报网（stcn.com）、IC Views（icviews.cn）、半导体行业观察（semiinsights.com）等专业资讯渠道中。这些信息数量大、更新快、涉及维度多，个人很难靠人工系统跟踪，更难以量化利用。正是在这样的背景下，本课题希望借助大数据与自然语言处理技术，对一定时期内的半导体行业舆情进行系统采集与挖掘，量化检验其中蕴含的多维信息效应，并实现有效的信息预警。

与聚焦个股交易行为的研究不同，本课题关注的是半导体行业整体，更看重行业层面的信息价值与研究方法在大科技领域的延展性。整个研究在选定的时间段内批量完成，不追求实时盯盘式的行情监测。具体来说，研究目的主要包括六个方面：一是完成三大资讯渠道的舆情数据采集与治理；二是构建覆盖"政策动态、技术进展、市场供需、企业动态、国际局势"五大类的多维主题分类体系；三是训练并横向对比多种情感分类模型，从中筛选最优模型；四是基于研究期数据，实证检验舆情信息在情绪、关注、主题、时效等维度上的分布特征、演化规律与相互关系；五是设计关键词触发、情绪突变、主题热度异常等信息预警机制；六是开发行业舆情可视化大屏，让研究成果真正落地为可用的产品。

本课题的意义可以从两方面来看。理论上，它把文本挖掘与情感分析从个股层面拓展到了产业层面，从多维信息视角检验半导体行业舆情的信息效应，能够丰富行业舆情分析与产业信息传播领域的实证研究。实践上，研究成果可以帮助行业研究者、企业战略部门与投资者把握半导体行业的舆情态势、热点演化与风险信号，为产业决策与风险预警提供数据支撑；同时，这套方法框架也可以平移到其他大科技细分行业的舆情分析中，具有较好的借鉴价值。

课题的主要内容可以概括为以下七个方面：

1. 证券时报网、IC Views、半导体行业观察三大渠道的半导体行业舆情数据采集、清洗与预处理；
2. 基于jieba分词与TF-IDF的文本特征工程，以及多维主题分类体系的构建；
3. FinBERT、朴素贝叶斯、随机森林三种情感分类模型的构建、调优与横向对比；
4. 舆情信息多维效应实证分析，涵盖情绪维度（正负面倾向与强度）、关注维度（报道量与浏览量）、主题维度（五大主题的分布与演化）、时效维度（事件响应与热度周期）的统计检验与关联分析；
5. 信息预警机制设计，包括关键词预警、情绪突变预警与主题热度异常预警，基于研究时间段批量检测实现；
6. 基于Flask与ECharts的半导体行业舆情可视化大屏开发；
7. 研究结论与对策建议。

## 2. 毕业设计（论文）的要求

本课题的主要工作内容与要求如下：

1. **文献综述。** 系统梳理国内外文本挖掘、情感分析、舆情信息效应与行业监测方面的文献，重点关注FinBERT等预训练语言模型在中文财经与产业文本中的应用现状，在此基础上明确本课题的研究切入点。

2. **数据采集与治理。** 针对证券时报网（stcn.com）、IC Views（icviews.cn）、半导体行业观察（semiinsights.com）三大渠道编写爬虫，采集选定研究时间段内的半导体相关资讯，字段应包含标题、正文、发布时间、来源、浏览量或互动量等；完成去重、去噪、格式统一等清洗工作，有效样本不少于3000篇。

3. **文本预处理与特征工程。** 完成数据清洗、jieba中文分词、停用词过滤与TF-IDF特征提取，构建规范、可复用的建模数据集。

4. **多维主题分类。** 构建"政策动态／技术进展／市场供需／企业动态／国际局势"五维主题体系，采用关键词词典与机器学习相结合的方式完成资讯的主题标注与分类。

5. **模型构建与对比。** 分别构建FinBERT、朴素贝叶斯、随机森林三种情感分类模型，使用GridSearchCV进行超参数调优并配合5折交叉验证，以准确率、精确率、召回率、F1值、混淆矩阵等指标客观评估，选出最优模型。

6. **多维信息效应实证分析。** 基于最优模型与主题分类结果，在研究时间段内对舆情信息的情绪、关注、主题、时效四个维度进行描述性统计、时间序列分析与相关性分析，检验各维度信息的分布特征、演化规律及相互作用。

7. **信息预警机制设计。** 基于规则引擎实现关键词预警（如"出口管制""制裁""涨价""减产""断供"等）、情绪突变预警与主题热度异常预警，采用定期批量检测方式，不要求实时行情监测。

8. **系统开发。** 基于Flask与ECharts开发行业舆情可视化大屏，包含行业情绪总览、多维主题对比、热词云、资讯趋势、重点舆情与预警列表等功能，做到界面清晰、交互流畅。

9. **论文撰写。** 按照学校毕业论文格式规范完成论文写作，做到结构完整、图表规范、数据真实、代码可复现，字数符合学校要求。

此外，要求严格遵守学术规范，杜绝抄袭，按时提交开题报告、中期检查材料与论文终稿；实验过程与结果必须真实可复现，保留完整的代码与数据集；按指导教师要求定期汇报进度，并根据意见及时修改完善。
