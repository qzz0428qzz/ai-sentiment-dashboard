# 毕业设计（论文）任务书

**论文题目：大数据视角下半导体板块舆情的多维信息效应实证研究**

---

## 1. 毕业设计（论文）的主要内容

**选题来源：** 本课题来源于大数据技术与产业信息分析交叉领域的现实需求。半导体产业是国家战略性产业，在国产替代加速与全球科技竞争加剧的背景下，行业政策、技术进展、市场供需与国际局势等信息密集涌现。这些信息广泛分布于证券时报网（stcn.com）、芯东西/集微网旗下的IC Views（icviews.cn）、半导体行业观察（semiinsights.com）等专业资讯渠道，具有信息量大、更新快、维度多、人工难以系统跟踪的特点。如何借助大数据与自然语言处理技术，对一定时期内的半导体行业舆情进行系统采集、挖掘与量化分析，检验其多维信息效应并实现信息预警，是产业研究与信息监测领域亟待解决的问题。

**研究目的：** 本课题以三大行业资讯网站的新闻报道与资讯文本为研究对象，面向半导体行业整体（而非单只股票的交易行为），构建"多源采集—文本挖掘—情感建模—多维实证—信息预警—可视化呈现"的完整研究框架，在选定研究时间段内开展批量式数据分析。具体目的包括：（1）完成三大渠道半导体行业舆情数据的采集与治理；（2）构建"政策动态/技术进展/市场供需/企业动态/国际局势"多维主题分类体系；（3）对比多种情感分类模型并筛选最优模型；（4）基于研究期数据实证检验舆情信息在情绪、关注、主题、时效等维度上的分布特征、演化规律与相互关系；（5）设计关键词触发、情绪突变、主题热度异常等信息预警机制；（6）开发行业舆情可视化大屏，实现研究成果的产品化落地。

**研究意义：**
- **理论意义：** 将文本挖掘与情感分析从个股层面拓展到产业层面，基于多维信息视角检验半导体行业舆情的信息效应，丰富了行业舆情分析与产业信息传播领域的实证研究。
- **实践意义：** 研究成果可帮助行业研究者、企业战略部门与投资者系统把握半导体行业的舆情态势、热点演化与风险信号，为产业决策、舆情监测与风险预警提供数据支撑，并对大科技领域其他行业的舆情分析具有方法上的延展性与借鉴价值。

**课题主要内容：**
1. 证券时报网、IC Views、半导体行业观察三大渠道的半导体行业舆情数据采集、清洗与预处理；
2. 基于jieba分词与TF-IDF的文本特征工程及多维主题分类体系构建；
3. FinBERT、朴素贝叶斯、随机森林三种情感分类模型的构建、调优与横向对比；
4. 舆情信息多维效应实证分析：情绪维度（正负面倾向与强度）、关注维度（报道量/浏览量）、主题维度（五大主题分布与演化）、时效维度（事件响应与热度周期）的统计检验与关联分析；
5. 信息预警机制设计：关键词预警、情绪突变预警、主题热度异常预警（基于研究时间段的批量检测）；
6. 基于Flask与ECharts的半导体行业舆情可视化大屏开发；
7. 研究结论与对策建议。

## 2. 毕业设计（论文）的要求

**主要工作内容与要求：**

1. **文献综述：** 系统梳理国内外文本挖掘、情感分析、舆情信息效应与行业监测相关文献，了解FinBERT等预训练语言模型在中文财经/产业文本中的应用现状，明确本课题的研究切入点。
2. **数据采集与治理：** 针对证券时报网（stcn.com）、IC Views（icviews.cn）、半导体行业观察（semiinsights.com）三大渠道编写爬虫，采集选定研究时间段内的半导体相关资讯（含标题、正文、发布时间、来源、浏览量/互动量等字段），完成去重、去噪、格式统一等清洗工作，有效样本不少于3000篇。
3. **文本预处理与特征工程：** 完成数据清洗、jieba中文分词、停用词过滤与TF-IDF特征提取，构建规范的建模数据集。
4. **多维主题分类：** 构建"政策动态/技术进展/市场供需/企业动态/国际局势"五维主题体系，采用关键词词典与机器学习相结合的方法对资讯进行主题标注与分类。
5. **模型构建与对比：** 分别构建FinBERT、朴素贝叶斯、随机森林三种情感分类模型，采用GridSearchCV进行超参数调优与5折交叉验证，以准确率、精确率、召回率、F1值、混淆矩阵等指标客观评估并选出最优模型。
6. **多维信息效应实证分析：** 基于最优模型与主题分类结果，在研究时间段内对舆情信息的情绪维度、关注维度、主题维度、时效维度进行描述性统计、时间序列分析与相关性分析，检验各维度信息的分布特征、演化规律及相互作用。
7. **信息预警机制：** 设计基于规则引擎的预警方案，包括关键词预警（如"出口管制""制裁""涨价""减产""断供"等）、情绪突变预警与主题热度异常预警，采用定期批量检测方式实现，不要求实时盯盘式的行情监测。
8. **系统开发：** 基于Flask + ECharts开发行业舆情可视化大屏，实现行业情绪总览、多维主题对比、热词云、资讯趋势、重点舆情与预警列表等功能，界面清晰、交互流畅。
9. **论文撰写：** 按照学校毕业论文格式规范撰写论文，结构完整、图表规范、数据真实、代码可复现，字数符合学校要求。

**其他要求：**
- 严格遵守学术规范，杜绝抄袭，按时提交开题报告、中期检查与论文终稿；
- 实验过程与结果须真实可复现，保留完整代码与数据集；
- 按指导教师要求定期汇报进度，及时修改完善。
