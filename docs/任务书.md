# 毕业设计（论文）任务书

**论文题目：大数据视角下半导体板块舆情的多维信息效应实证研究**

---

## 1. 毕业设计（论文）的主要内容

**选题来源：** 本课题来源于大数据技术与资本市场行为金融研究的前沿交叉领域。近年来，在国产替代加速与全球科技竞争加剧的背景下，半导体板块成为A股市场关注度最高的投资赛道之一，东方财富股吧等网络社区积累了海量投资者舆情文本。这些舆情蕴含着丰富的市场情绪与关注信息，并可能对股票价格、波动与交易活跃度产生实质性影响。如何借助大数据与自然语言处理技术，从非结构化舆情文本中挖掘多维信息并检验其市场效应，已成为金融科技领域亟待解决的现实问题。

**研究目的：** 本课题以半导体板块代表性上市公司（如中芯国际、北方华创、韦尔股份、兆易创新、长电科技等）的股吧评论与行情数据为研究对象，构建"数据采集—文本挖掘—情感建模—实证检验—可视化呈现"的完整研究框架。具体目的包括：（1）完成半导体板块舆情数据与行情数据的采集与治理；（2）对比多种情感分类模型并筛选最优模型；（3）构建情绪指数与关注度等多维信息指标，实证检验舆情信息对股票收益、波动性与交易活跃度的影响；（4）开发舆情监测可视化大屏，实现研究成果的产品化落地。

**研究意义：**
- **理论意义：** 将文本情感分析与多维信息效应检验引入半导体板块研究，丰富了财经舆情信息效应与行为金融领域的实证文献，为理解投资者情绪如何影响资产价格提供了新的行业证据。
- **实践意义：** 研究成果可帮助投资者实时感知半导体板块市场情绪与热点事件，辅助投资决策；同时可为监管部门与上市公司提供舆情监测与风险预警参考，具有一定的应用价值。

**课题主要内容：**
1. 半导体板块股吧舆情数据与行情数据的采集、清洗与预处理；
2. 基于jieba分词与TF-IDF的文本特征工程；
3. FinBERT、朴素贝叶斯、随机森林三种情感分类模型的构建、调优与横向对比；
4. 情绪指数与关注度等多维信息指标的构建，及其对股票收益、波动、交易活跃度影响的实证检验；
5. 基于Flask与ECharts的半导体板块舆情监测可视化大屏开发；
6. 研究结论与对策建议。

---

## 2. 毕业设计（论文）的要求

**主要工作内容与要求：**

1. **文献综述：** 系统梳理国内外金融文本挖掘、情感分析与舆情信息效应相关文献，了解FinBERT等预训练语言模型在金融情感分析中的应用现状，明确本课题的研究切入点。
2. **数据采集与治理：** 编写爬虫采集东方财富股吧半导体板块代表性个股的评论数据（含标题、正文、发布时间、阅读量、回复量等字段），并通过AKShare获取对应行情数据；完成去重、去噪、去水帖等清洗工作，有效样本不少于2000条。
3. **文本预处理与特征工程：** 完成数据清洗、jieba中文分词、停用词过滤与TF-IDF特征提取，构建规范的建模数据集。
4. **模型构建与对比：** 分别构建FinBERT、朴素贝叶斯、随机森林三种情感分类模型，采用GridSearchCV进行超参数调优与5折交叉验证，以准确率、精确率、召回率、F1值、混淆矩阵等指标客观评估并选出最优模型。
5. **实证分析：** 基于最优模型构建个股与板块情绪指数，结合阅读量、发帖量等关注度指标，运用相关分析、回归分析等方法，实证检验舆情多维信息（情绪维度、关注维度）对股票收益率、波动率与交易活跃度的影响。
6. **系统开发：** 基于Flask + ECharts开发可视化大屏，实现板块情绪总览、细分领域（芯片设计/制造/封测/设备材料）对比、个股情绪下钻等功能，界面清晰、交互流畅。
7. **论文撰写：** 按照学校毕业论文格式规范撰写论文，结构完整、图表规范、数据真实、代码可复现，字数符合学校要求。

**其他要求：**
- 严格遵守学术规范，杜绝抄袭，按时提交开题报告、中期检查与论文终稿；
- 实验过程与结果须真实可复现，保留完整代码与数据集；
- 按指导教师要求定期汇报进度，及时修改完善。
